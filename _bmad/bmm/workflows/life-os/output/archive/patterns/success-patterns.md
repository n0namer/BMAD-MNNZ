## Pattern Discovery Process

**How patterns are added:**

1. **Quarterly Review (Step V-04):** System analyzes all completed retrospectives
2. **Pattern Threshold:** Requires 3+ ideas showing same pattern
3. **Confidence Scoring:**
   - HIGH: 5+ data points, consistent results
   - MEDIUM: 3-4 data points, mostly consistent
   - LOW: 2 data points, preliminary observation

4. **User Approval:** All patterns presented to user before adoption

**Auto-Application:**

Patterns with HIGH confidence automatically trigger recommendations during:
- Step 02: Scoring (complexity adjustments)
- Step 03: Make Plan (timeline adjustments)
- Step 08: Deep Plan (architecture recommendations)
