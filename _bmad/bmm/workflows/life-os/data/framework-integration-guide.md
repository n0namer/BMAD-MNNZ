# Framework Integration Guide

Purpose
- Define how multiple frameworks are combined in Life OS without conflicts.
- Provide a consistent integration checklist for consilium, scoring, and deep planning.

Integration Order (default)
1. Domain discovery and classification
2. Select 1-3 primary frameworks
3. Add supporting frameworks only if they do not introduce conflicting assumptions
4. Resolve conflicts using TRIZ when trade-offs appear

Compatibility Rules
- Prefer frameworks that share compatible time horizons (short/medium/long).
- Avoid overlapping frameworks that duplicate identical steps.
- If two frameworks require different decision criteria, surface the contradiction before scoring.

Minimum Output
- Primary frameworks list
- Supporting frameworks list (optional)
- Conflict notes (if any)
- Integration summary (3-7 bullets)
