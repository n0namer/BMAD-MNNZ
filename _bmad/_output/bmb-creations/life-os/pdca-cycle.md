# PDCA Cycle: Plan-Do-Check-Act for Life OS

**Framework:** ISO 9001 quality management applied to goal tracking

**Levels:** Daily → Weekly → Monthly → Quarterly → Yearly

**Purpose:** Systematic review and continuous improvement of progress toward goals

---

## 🔄 PDCA FRAMEWORK OVERVIEW

```
PLAN (Плани́руй)
  ↓
DO (Дела́й)
  ↓
CHECK (Провéри)
  ↓
ACT (Дей́ствуй)
  ↓
[Loop back to PLAN]
```

---

## 📋 DAILY LEVEL (5-10 min review)

**When:** Every evening before bed

**PLAN:**
- [ ] What are today's top 3 priorities?
- [ ] Blocked by anything?

**DO:**
- [ ] Work on priorities
- [ ] Track hours (by project)
- [ ] Note blockers

**CHECK:**
- [ ] Did I complete my priorities? (Y/N)
- [ ] How many hours worked? (target: 6-8h)
- [ ] Health check: Fitness? Food? Sleep?
- [ ] Mood/Energy: 1-10?

**ACT:**
- [ ] Adjust tomorrow's plan if needed
- [ ] Celebrate wins
- [ ] Note for weekly review

**Template:**

```
DATE: [YYYY-MM-DD]

TOP 3 PRIORITIES:
1. [Project] - [Task]
2. [Project] - [Task]
3. [Personal] - [Task]

ACTUAL WORK:
- [Project1]: [hours worked] hours
- [Project2]: [hours worked] hours
- Total: [sum] hours

HEALTH:
- Fitness: [Y/N] - [notes]
- Food: [notes]
- Sleep: [hours]
- Energy: [1-10]

BLOCKERS:
- [What prevented progress?]

TOMORROW:
- [Adjusted priorities?]

MOOD: [Positive/Neutral/Challenged]
```

## 📅 WEEKLY LEVEL (30-60 min review)

**When:** Every Friday evening (weekly standup)

**PLAN:**
- Review week's goals (from Monday)
- Adjust next week's priorities
- Resource/capacity check

**DO:**
- Execute daily tasks
- Log hours per project
- Track progress on week-long goals

**CHECK:**
- Completed how many daily priorities? (%)
- Hours per project vs. planned?
- Health habits maintained?
- Revenue/metrics on track?

**ACT:**
- What's working? → Keep doing
- What's not? → Change approach
- Blockers to remove?
- Celebrate weekly wins
