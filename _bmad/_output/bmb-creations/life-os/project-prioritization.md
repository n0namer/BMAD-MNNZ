## 📝 DECISION RULES

### When to PAUSE a project:
1. ❌ If it threatens income generation (Katana priority)
2. ❌ If it's not aligned with 1млн goal
3. ❌ If you're too tired/overwhelmed
4. ❌ If dependencies aren't met (e.g., 002 before 005)

### When to SKIP a project:
1. ❌ If it requires hands-on daily work (007 Beauty)
2. ❌ If timeline doesn't align (2027 projects)
3. ❌ If revenue potential < $1K/month and not urgent

### When to ACCELERATE:
1. ✅ If Katana performs better than expected
2. ✅ If Sales QA reaches profitability faster
3. ✅ If health recovery is ahead of schedule
4. ✅ If you have extra energy/capacity
