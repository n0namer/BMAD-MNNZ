## 🎯 РЕКОМЕНДУЕМАЯ СТРУКТУРА (MVP)

Предлагаю **систему с 3 файлами**:

### **ФАЙЛ 1: `ideas_inbox.csv` — Входящие идеи (новые, необработанные)**

```csv
id,date_added,source,raw_idea,category,status
1,2026-01-27,voice_notes,"ИИ может заменить контент-менеджера за 3 часа",automation,new
2,2026-01-27,client_question,"Как настроить речевой ввод на Windows?",tech_pain,new
3,2026-01-27,trend,"Кризис — люди ищут экономию",market_trend,new
4,2026-01-28,own_experience,"Я написал 80 документов за 3 часа через регламенты",llm_hack,new
```

**Колонки:**

- `id` — уникальный номер
- `date_added` — когда добавил идею
- `source` — откуда идея (voice_notes, client_question, trend, own_experience, dialog, article)
- `raw_idea` — сама идея (как ты её высказал)
- `category` — категория (automation, tech_pain, market_trend, llm_hack, pricing, workflow)
- `status` — статус (new, researched, expanded, posted, archived)

***

### **ФАЙЛ 2: `ideas_research.csv` — Исследованные и развёрнутые идеи**

```csv
id,original_idea_id,research_date,main_angle,sub_angles_count,data_found,sources_count,best_angle,status
1,1,2026-01-27,"Экономия времени с ИИ",5,"Люди теряют 40% времени на рутину",7,"Экономия для владельцев агентств",researched_ready
```

**Колонки:**

- `id` — уникальный номер
- `original_idea_id` — ссылка на идею из inbox
- `research_date` — когда исследовал
- `main_angle` — главный угол атаки
- `sub_angles_count` — сколько углов выявил (5-10 вариантов)
- `data_found` — ключевые данные (статистика, факты)
- `sources_count` — сколько источников нашёл
- `best_angle` — какой угол выбрал для первого поста
- `status` — статус (researched_ready, posted, archived)

***

### **ФАЙЛ 3: `posts_published.csv` — Готовые посты (история)**

```csv
id,research_id,publish_date,platform,post_title,angle_used,ctr_or_engagement,notes
1,1,2026-01-27,telegram,"ИИ заменит твоего помощника",angle_3,120_views,"Хороший старт"
```

**Колонки:**

- `id` — номер поста
- `research_id` — ссылка на исследование
- `publish_date` — когда опубликовал
- `platform` — где опубликовал (telegram, instagram, youtube)
- `post_title` — заголовок поста
- `angle_used` — какой угол использовал (angle_1, angle_2, и т.д.)
- `ctr_or_engagement` — результаты (просмотры, клики, комментарии)
- `notes` — заметки (что сработало, что нет)

## 🔄 WORKFLOW С ЭТИМИ ФАЙЛАМИ

```
ШАГ 1: Ты говоришь идею
└─ Ты (или I) добавляешь в ideas_inbox.csv

ШАГ 2: Я исследую + развиваю
├─ Ищу в интернете лучшие практики
├─ Выявляю 5-10 углов атаки
├─ Сохраняю результат в ideas_research.csv
└─ Показываю тебе список углов

ШАГ 3: Ты выбираешь угол
└─ "Развиваю угол #3 в пост сегодня"

ШАГ 4: Я структурирую пост
├─ Делаю исследование по выбранному углу
├─ Пишу пост (хук → проблема → решение → триггер → CTA)
└─ Даю готовый пост

ШАГ 5: Ты публикуешь + я фиксирую результаты
├─ Публикуешь в Telegram/Instagram
├─ Ты сообщаешь результаты (просмотры, клики)
└─ Я добавляю в posts_published.csv

ШАГ 6: Завтра берёшь угол #1, послезавтра #2
└─ Получаешь контент на всю неделю из одной идеи
```

```

```

```

4. **Опубликовать + отследить:**

```
