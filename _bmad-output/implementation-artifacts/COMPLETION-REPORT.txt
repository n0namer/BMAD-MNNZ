POTENTIAL ISSUES & QUICK FIXES
================================================================================

Issue: "Too many connections" error
──────────────────────────────────
Cause:     Connection pool too small
Solution:  Set pool_size=30, max_overflow=50 in conftest.py
Where:     DB-TEST-ISOLATION-IMPLEMENTATION.md Part 2

Issue: Tests timeout in parallel execution
───────────────────────────────────────────
Cause:     Tests waiting for locks (race conditions)
Solution:  Ensure transaction isolation is working
Action:    Run locally with -n 4 to reproduce

Issue: PostgreSQL service won't start in CI
────────────────────────────────────────────
Cause:     Port already in use or resource limits
Solution:  Use different port: ports: [5433:5432]
Where:     github-actions-db-isolation.yaml

Issue: Tests pass locally, fail in CI
──────────────────────────────────────
Cause:     Parallel execution reveals existing race conditions
Solution:  This is actually good - fix the race conditions
Action:    Test locally with -n 4: pytest tests/ -n 4

For more issues: See DB-TEST-ISOLATION-IMPLEMENTATION.md Part 10
