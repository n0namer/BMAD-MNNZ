# Софт для контроля качества отдела продаж (расширенный)

## Brief Description
Комплексная платформа для РОПов и менеджеров:
- **Для РОП:** транскрибация звонков, анализ по книге продаж, статистика по менеджерам/воронке/качеству
- **Модуль генерации:** автосоздание книги продаж и скриптов
- **Для менеджеров:** real-time AI-ассистент слушает разговор, анализирует карточку клиента, подсказывает что говорить

## Motivation
РОПы тратят часы на прослушку звонков вручную. Менеджеры теряют сделки из-за неправильных ответов. Автоматизация + AI = контроль качества + рост конверсии.

## Design Thinking: Empathy Framing
**Who Benefits:** РОПы (экономия времени), менеджеры (повышение конверсии), компании (рост продаж)
**Pain/Problem Solved:** Ручной контроль качества невозможен при >10 менеджерах; менеджеры теряют сделки из-за незнания продукта
**Why Now:** AI-транскрибация и real-time анализ стали доступны, конкуренты начинают использовать

## Stakeholders
- РОПы (руководители отделов продаж)
- Менеджеры по продажам
- Собственники бизнеса (заинтересованы в росте выручки)

## Initial Thoughts
**Модули:**
1. Транскрибация + анализ (Whisper API, GPT для оценки качества)
2. Генерация книг продаж и скриптов (RAG + prompt engineering)
3. Real-time ассистент (WebSocket, live transcription, карточка клиента в CRM)

**Интеграции:** Телефония (Mango, Zadarma), CRM (Битрикс24, amoCRM)

## Timeline Expectation
MVP (транскрибация + базовая аналитика): 2-3 месяца
Полный продукт: 6-9 месяцев

## Resource Estimate
200-400 часов разработки, API транскрибации (платно), хостинг, БД
