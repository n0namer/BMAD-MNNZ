# Katana-VectorBT - Торговая платформа автономных стратегий

## Brief Description
Автономная платформа для разработки, тестирования и масштабирования торговых стратегий на основе VectorBT. Цель: достичь ≥3 стратегий в статусе Scaled-Live за 90 дней (до 2026-05-04) для генерации пассивного дохода.

## Motivation
Создание системы пассивного дохода через автоматизированный трейдинг. Платформа включает массовую оптимизацию (52 параметра, 665,600 прогонов), статический HTML-дашборд, интеграцию с ценовыми данными и новостным календарём. Фазы 3-4 завершены (173/173 задачи), Epic L в процессе (8/11 историй).

## Design Thinking: Empathy Framing
**Who Benefits:** Пользователь (разработчик стратегий), потенциальные клиенты (инвесторы)
**Pain/Problem Solved:** Ручная оптимизация стратегий занимает недели; нужна автоматизация для массового тестирования и отбора прибыльных стратегий
**Why Now:** Фазы 3-4 завершены, Epic L в разработке, цель 90 дней до 2026-05-04

## Stakeholders
- Nikita (владелец проекта, разработчик)
- Потенциальные инвесторы (при Scaled-Live запуске)
- Пользователи дашборда (визуализация стратегий)

## Initial Thoughts
Проект в стадии активной разработки. Архитектура определена (4-layer UI: Static HTML + Jupyter + katana/ library). Массовая оптимизация через Epic J (33,280 стратегий). Price Action + News Calendar через Epic L. Инфраструктура готова, остались интеграционные задачи.

## Timeline Expectation
90 дней до 2026-05-04 (SMART goal: ≥3 стратегии Scaled-Live)

## Resource Estimate
- Время: 8-12 часов/неделю на Epic L
- Инфраструктура: VectorBT, Jupyter, статический HTML, Python
- Данные: API для исторических цен и новостного календаря
- Риски: интеграция Price Action, валидация Live Trading
