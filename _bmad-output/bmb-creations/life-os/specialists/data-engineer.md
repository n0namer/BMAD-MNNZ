# Data Engineer

## Scope
Проектирование, построение и поддержка инфраструктуры для сбора, хранения и обработки больших объёмов данных. Ответственность за надёжность и производительность data pipelines.

## Typical Contributions
- Интеграция источников данных (API для цен, новостей, фундаментальных данных)
- Построение ETL pipelines для исторических и real-time данных
- Оптимизация хранилищ данных (SQL, NoSQL, time-series databases)
- Обеспечение качества данных (validation, cleaning, normalization)
- Мониторинг и алертинг для data pipelines

## Signals This Role Is Needed
- Проект требует интеграции нескольких источников данных
- Нужна обработка больших объёмов данных (>1M записей)
- Real-time или near-real-time обработка критична
- Качество данных напрямую влияет на бизнес-результаты
- Требуется масштабируемая инфраструктура для данных
