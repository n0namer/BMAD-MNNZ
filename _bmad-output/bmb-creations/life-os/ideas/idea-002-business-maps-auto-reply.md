# Автоответчик для карт (Яндекс/Google/Zoon)

## Brief Description
Бот для автоматических ответов на отзывы клиентов в Яндекс Картах, Google Maps и Zoon.

## Motivation
Компании игнорируют отзывы из-за нехватки времени → падает рейтинг. Автоматизация повышает вовлечённость и репутацию.

## Design Thinking: Empathy Framing
**Who Benefits:** Владельцы бизнеса, SMM-менеджеры
**Pain/Problem Solved:** Нет времени отвечать на отзывы → падает доверие клиентов
**Why Now:** Отзывы критичны для локального бизнеса

## Stakeholders
- Владельцы локального бизнеса (рестораны, салоны)
- SMM-менеджеры
- Клиенты

## Initial Thoughts
API интеграция с платформами, шаблоны ответов, опциональная модерация.

## Timeline Expectation
MVP: 2-4 недели, полный продукт: 2-3 месяца

## Resource Estimate
40-80 часов разработки, хостинг, БД
