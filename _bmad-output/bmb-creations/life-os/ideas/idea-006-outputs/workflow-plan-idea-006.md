# Life OS Workflow Plan: Idea 006

## Исходная идея

**ID:** idea-006
**Название:** Универсальный SaaS ассистент-консилиум
**Домен:** бизнес/софт/личное/AI
**Пользовательский ввод:** "универсальный SaaS ассистент-консилиум, с разными режимами, например, модератор встречи, который на ходу ищет лучшие решения, раскидывает по проектам, советует по всем сферам жизни, по сути как life os - этот воркфлоу"

## Краткое описание

Мультирежимный AI-ассистент с функциями:
- Модератор встречи (real-time поиск лучших решений)
- Распределение задач по проектам
- Консультант по всем сферам жизни (бизнес/финансы/здоровье/личное)
- Аналог Life OS workflow в виде SaaS продукта

## Мотивация

Люди тонут в задачах, встречи неэффективны, нет единого места для консультаций по разным сферам. SaaS-версия Life OS = доступ для всех, подписочная модель.

## Временные ожидания

MVP: 3-4 месяца, полный продукт: 12 месяцев

## Оценка ресурсов

400-800 часов разработки, API AI (дорого), инфраструктура SaaS

## Consilium Recommendations (Six Hats) (Шаг 4)

**Mode:** Deep
**Specialists Consulted:**
- **Market Analyst** (⚪ White Hat - Facts): TAM $15.7B, SAM $2.3B, SOM $5-10M/год. Конкуренты: Notion AI ($10), Motion ($34), Superhuman ($30). Средний churn 5-7%. Вывод: рынок насыщен, но есть ниша для "универсального консилиума"
- **Finance Analyst** (⚪ White Hat - Facts): COGS $0.70-1.70/user/месяц, цена $15/мес, LTV:CAC = 5.6:1 при 15 мес подписки. Break-even: 1000+ платных пользователей
- **Creative Director** (🔴 Red Hat - Intuition): Концепт сильный ("personal board of advisors"), но риск быть "посредственным везде". Нужно начать с 1-2 killer режимов
- **Finance Analyst** (⚫ Black Hat - Risks): Критичные риски - API cost spiral при масштабе ($50-150k/мес при 10k users), PMF uncertainty, development time (3-4 мес оптимистично), data privacy
- **Product Strategist** (🟡 Yellow Hat - Benefits): All-in-one value (vs 5-10 tools), "consilium effect" (разные перспективы), premium positioning $15-30/мес, Life OS = proven methodology
- **Creative Director** (🟢 Green Hat - Creativity): Specialist personas UI (drag-and-drop консилиум), Decision Dashboard с MCDA встроен, Workflow Templates marketplace, Live Meeting Mode с auto-framework detection
- **Product Strategist** (🔵 Blue Hat - Process): MVP 2 режима (Meeting Moderator + Task Distributor), 10 недель разработки, beta 50-100 users, метрики: Week 1 retention >40%, LTV:CAC >3:1

**Consensus View (Balanced):**
- ✅ **Go with conditions**: Идея сильная, но требует узкого MVP фокуса (2 режима, не "универсальный")
- 🎯 **Positioning**: "Consilium as a Service" - Personal Board of Advisors (не "ещё один AI assistant")
- 💰 **Financial guardrails**: Max API spend $5k/мес в MVP, target 100 paying users к Month 3 ($1.5k MRR)
- 🚀 **Differentiation**: Specialist personas + Six Hats UI, workflow templates, structured guidance
- ⚠️ **Key risks**: API cost spiral (monitor weekly), PMF validation (beta retention >40%), feature creep

**Auto-Suggest Framework Detection:**
- **Confidence: 85%** (consilium выявил противоречия)
- **Suggested framework:** TRIZ (optional) - если нужно разрешить противоречие "универсальность vs специализация"
