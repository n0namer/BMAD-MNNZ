## Зависимости между модулями

```
МОДУЛЬ 2 (Генератор KB)
        ↓ (embeddings)
МОДУЛЬ 3 (RT Assistant) использует embeddings для подсказок
        ↑ (качество)
МОДУЛЬ 1 (QA Dashboard) использует ту же KB для scoring
```

**Критические зависимости:**
- Модуль 3 ТРЕБУЕТ Модуль 2 (нужна книга продаж для подсказок)
- Модуль 1 может работать БЕЗ Модуля 2 (если книга продаж загружена вручную)

**Рекомендуемая последовательность:**
1. Модуль 1 (MVP) → validate с клиентами
2. Модуль 2 → снижает барьер входа
3. Модуль 3 → killer feature, дифференциация
