# Универсальный SaaS ассистент-консилиум

## Brief Description
Мультирежимный AI-ассистент с функциями:
- Модератор встречи (real-time поиск лучших решений)
- Распределение задач по проектам
- Консультант по всем сферам жизни (бизнес/финансы/здоровье/личное)
- Аналог Life OS workflow в виде SaaS продукта

## Motivation
Люди тонут в задачах, встречи неэффективны, нет единого места для консультаций по разным сферам. SaaS-версия Life OS = доступ для всех, подписочная модель.

## Design Thinking: Empathy Framing
**Who Benefits:** Предприниматели, менеджеры, команды, физлица (личная эффективность)
**Pain/Problem Solved:** Хаос в задачах, неэффективные встречи, нет персонального советника
**Why Now:** AI-консилиумы стали возможны (GPT-4, Claude), люди готовы платить за эффективность

## Stakeholders
- Пользователи (предприниматели, менеджеры, физлица)
- Команды (совместные проекты)

## Initial Thoughts
**Режимы:**
1. Модератор встречи (транскрибация → генерация решений → раскидка задач)
2. Консилиум (Six Thinking Hats, TRIZ, Design Thinking)
3. Личный советник (финансы, здоровье, карьера)
4. Управление проектами (как Life OS)

**Монетизация:** Freemium (базовый бесплатно) + подписка ($10-50/мес)

## Timeline Expectation
MVP: 3-4 месяца, полный продукт: 12 месяцев

## Resource Estimate
400-800 часов разработки, API AI (дорого), инфраструктура SaaS
