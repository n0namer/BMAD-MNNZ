# Идея 007: Бьюти-франшиза — Consilium Recommendations (Six Hats)

**Date:** 2026-02-05
**Mode:** Deep (10 специалистов)

## Специалисты консультировали:

### ⚪ White Hat (Факты и данные):
- **Finance Analyst:** Финмодель есть, НО нет unit-economics, ROI калькулятора. Требуется: первоначальный взнос, роялти, break-even, средняя прибыль франчайзи

- **CRM / Automation:** Битрикс24 подходит (воронка, чек-лист, база знаний). Аттестация требует кастома или внешнего LMS

- **Market Analyst:** Список городов есть, но нет анализа конкурентов и приоритизации. Бренд-путаница (DepylBrazil vs Saxap) критична

### ⚫ Black Hat (Риски):
- **Legal / Compliance:** 4 критических риска:
  1. Нет договора коммерческой концессии
  2. Бренд-путаница
  3. Нет контроля качества
  4. Unclear governance (кто владелец?)

### 🟡 Yellow Hat (Преимущества):
- **Growth / GTM:** Опорная студия = proof-of-concept, 40-50% работы готово, команда продаж есть, рынок растёт. Quick win: упаковать 1 точку → метрики → кейс для продаж

### 🟢 Green Hat (Творчество):
- **Franchise Consultant:** Альтернативы: micro-франшиза, SaaS-модель, партнёрская программа. Data Room best practices. Гибридная модель: Franchise Light vs Premium

- **Curriculum Designer:** Геймификация (3 уровня), peer learning (чат франчайзи), live workshops с Галиной раз в месяц

### 🔴 Red Hat (Интуиция):
- **Change Management:** Чувствуется напряжение между стейкхолдерами (кто главный?). Никита требует оплачиваемый пилот = защитная реакция. Нужен alignment meeting ДО технической работы

### 🔵 Blue Hat (Процесс):
- **Product Strategist:** 3 фазы: (1) Plan-Razvedka 48-72ч, (2) Пилот 2-4 недели, (3) Полная система 3-6 мес

- **Operations Lead:** Стандартизация = приоритет. Чек-лист 30 дней, SOP для критических процессов

## Консенсус View (Balanced Multi-Perspective):

### Критический путь:
1. ⚠️ **Сначала:** Исправить бренд-путаницу + alignment meeting (governance)
2. 🔍 **Plan-Razvedka (48-72ч):** Gap-анализ + выбор One Goal для пилота
3. 🚀 **Пилот (2-4 недели):** Реализация выбранной цели
4. 📦 **Полная система (3-6 мес):** Data Room + Битрикс24 + обучение

### ⚠️ Red Flags (блокеры):
- Бренд-путаница (DepylBrazil vs Saxap)
- Governance unclear (кто владелец?)
- Нет юридической упаковки (договор коммерческой концессии)

### ✅ Green Lights:
- Опорная студия (proof-of-concept)
- Команда продаж (Виолетта + Мария)
- Битрикс24 технически подходит

## Главная рекомендация:
НЕ начинать пилот ДО решения 3 Red Flags. Иначе риск юридических проблем, конфликтов стейкхолдеров, репутационного ущерба.
