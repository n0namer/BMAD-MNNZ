EXECUTIVE SUMMARY
================================================================================

The Content Machine Pipeline is a sophisticated 5-stage system that transforms
routine demonstrations into native sales content through:

  Stage 1: INPUT — Screenshot + description capture (Vision API analysis)
  Stage 2: PAIN — Automated business pain point generation per angle
  Stage 3: OFFERS — On-the-fly product offer generation (filter-respecting)
  Stage 4: DRAFT — 3 post variants with intelligently embedded offers
  Stage 5: VARIANTS — 3 additional variants using alternative frameworks

Key Innovation: Automated offer generation that responds to user preferences,
eliminating the need for manual offer creation while ensuring quality and
relevance.
